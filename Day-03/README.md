College Database Design
Project Description

This project demonstrates the design of a simple college database using SQLite.
The database contains three tables: students, departments, and courses.

Technologies Used
SQLite
SQL

Database Tables
Students – Stores student details such as ID, name, age, department, and CGPA.
Departments – Stores information about different college departments.
Courses – Stores course details and credits.

SQL Operations Performed
Created database tables
Inserted 10 student records
Retrieved student data using SELECT
Used WHERE conditions to filter data
Used aggregate functions
Used GROUP BY queries

Aggregate Functions Used
COUNT() – Counts the total number of students.
AVG() – Calculates the average CGPA of students.
MAX() – Finds the highest CGPA.
MIN() – Finds the lowest CGPA.
SUM() – Calculates the total of all CGPA values.
