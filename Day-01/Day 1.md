# Git & GitHub – Day 1

**Date:** 18 August 2026

## Topics Learned

Today I learned the basics of **Git and GitHub**, including how Git is used for version control and how GitHub is used to store and collaborate on projects remotely.

### Git

Git is a **distributed version control system** that helps us track changes in our code and manage different versions of a project.

### GitHub

GitHub is an online platform where Git repositories can be stored, shared, and collaborated on with other developers.

## Git Commands Learned

* 'git init' – Initializes a Git repository.
* 'git clone' – Copies a remote repository to the local computer.
* 'git status' – Shows the current status of the repository.
* 'git add .' – Adds all changed files to the staging area.
* 'git commit -m "message"' – Saves the changes with a meaningful message.
* 'git push' – Uploads local commits to the remote GitHub repository.
* 'git pull' – Downloads the latest changes from the remote repository and updates the local repository.

## Basic Git Workflow

'''text
Create/Modify Files
       ↓
   git status
       ↓
    git add .
       ↓
 git commit -m "message"
       ↓
    git push
       ↓
     GitHub
'''

## GitHub Collaboration

I also learned how Git and GitHub can be used when working with other people. A repository can be cloned, modified, committed, and pushed so that changes can be shared with the team.

## Commands Practiced

git status
git add .
